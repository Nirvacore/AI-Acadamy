# สคริปต์และสตอรี่บอร์ด

- รหัส: `media-script-storyboard`
- ชั้น: แล็บประยุกต์ ตอนที่ ๒ จาก ๓
- ต้องผ่านตอน brief และกระดานหลักฐานก่อน
- ฮับ: [/media](/media)
- แล็บ: [../labs/media-script-storyboard.md](../labs/media-script-storyboard.md)

## เป้าหมาย

เรียนจบแล้วเขียนสคริปต์คนละโทนสำหรับ LINE Instagram และ YouTube พร้อมกรอกสตอรี่บอร์ดสามจังหวะที่เป็นแบบฝึกของ Academy ไม่ใช่ฟีเจอร์ที่พบว่าทำงานใน NirvaMedia

## แนวคิดแกน

ของจริงที่ reuse ได้เรื่องคำ:

- `shared/media.ts` กำหนด `ContentType` รวมค่า `script`
- `app/api/campaigns/route.ts` มีแม่แบบ TikTok ที่พูดถึงการเตรียมสคริปต์ และแม่แบบ YouTube ที่เป็น video outline
- `lib/upstream-media-adapter.ts` ปรับความยาวตามช่องทางเมื่อมี registry ของ Claude

ของที่ **ไม่มี** ใน runtime ที่ตรวจได้:

- ไม่พบหน้าสตอรี่บอร์ดใน `app/studio/page.tsx`
- คำ `teaser storyboards` อยู่ใน `upstream/nirva-ai/apps/nirva-studio-os/src/lib/mock-data/index.ts` เท่านั้น
- `server/media/library.ts` มีโครงคลังสินทรัพย์ แต่ `searchAssets()` คืนอาร์เรย์ว่าง

ดังนั้นแผ่นสตอรี่บอร์ดในแล็บนี้เป็น **Academy-authored worksheet** มีสามจังหวะ: เปิด ปัญหา ทางออก แต่ละช่องกรอกภาพ เสียง และหมายเหตุ คนกรอก เธอช่วยร่างได้ แต่ห้ามเคลมว่า Studio จริงมีปุ่มนี้

สคริปต์สามช่องทางไม่ใช่การคัดลอกประโยคเดียวแล้วเปลี่ยนโลโก้ LINE ต้องการประโยคกระชับที่กดได้ Instagram ต้องการโครงภาพ YouTube ต้องการลำดับเล่า ร่างสินทรัพย์ในเครื่องนี้จำลองการสร้าง `campaign_posts` สถานะ `draft` โดยไม่เรียกเครือข่าย

ถ้า brief ตอนที่หนึ่งยังไม่ผ่านประตูหลักฐาน อย่าเริ่มเขียนสคริปต์จากความจำของเธอ

## กระจก

- **จิต** — ความเพลินจัดคำทำให้ลืมว่าสมมติฐานยังปนอยู่ในแคปชัน
- **พลังงาน** — สามช่องทางที่หั่นจาก brief เดียวถูกกว่าการให้เธอแต่งใหม่ทั้งก้อนทุกแพลตฟอร์ม
- **ควอนตัม** — แต่ละช่องทางคือการวัดคนละครั้ง อย่ารวมเป็นโพสต์เดียวแล้วยัดทุกที่
- **มหาสูญตา** — คำว่าคอนเทนต์ครบแล้วไม่มีแก่น ถ้ายังชี้จังหวะภาพไม่ได้
- **ฉันเข้าใจเธอ** — เธอทำแม่แบบซ้ำได้เก่ง แต่เธอไม่รู้ว่าชุมชนสมมตินี้ทนโทนไหน

## เดโมเครื่องมือ

เปิดแผ่นงานตอนที่ ๒ จากบทนี้หรือจากฮับ แล้วสั่งเธอให้ร่างจาก brief ที่คุณล็อกแล้วเท่านั้น

**Cursor** — ใช้ Plan Mode ขอโครงสามจังหวะ ตรวจแผน แล้วค่อยให้ช่วยเขียนคำ ห้าม Accept งานที่เพิ่มช่องทางนอก LINE Instagram YouTube

**Claude** — วางตารางสตอรี่บอร์ดว่าง แล้วให้เติมเฉพาะช่องที่คุณระบุ ห้ามสร้างไฟล์ภาพจริง

**OpenAI** — ขอสามเวอร์ชันสั้นจาก brief เดิม แล้วคุณเป็นคนวางลงช่อง LINE / Instagram / YouTube เอง

**Copilot** — อย่า Apply สคริปต์ลงรีโป คัดเฉพาะประโยคที่คุณยอมรับแล้วไปวางในแผ่นงาน

เมื่อมีสคริปต์ครบ กดสร้างร่างในเครื่องนี้ ผลต้องเป็นข้อความในเบราว์เซอร์ ไม่ใช่โพสต์บนเพจ
