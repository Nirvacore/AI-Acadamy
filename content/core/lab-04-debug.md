## เป้าหมาย

เรียนจบแล้วตั้งสมมติฐานจากเทสที่ล้ม แล้วพิสูจน์ก่อนแก้ ไม่เดาจากความรู้สึก

## แนวคิดแกน

เทสที่ล้มคือเครื่องมือวัด ข้อความเทสบอกกฎที่ต้องการ ชื่อเทสบอกเคส อย่าเริ่มย้ายบรรทัดก่อนอ่านผลรัน

สมมติฐานที่ดีชี้ได้ว่าบรรทัดไหนผิด แล้วมีวิธีฟ้อง เช่น รันเคสซื้อ 3 ชิ้น แล้วดูว่าเงื่อนไข `qty > 3` ทำให้ 3 ไม่ลด

แก้ทีละสมมติฐาน ถ้ารันแล้วยังล้ม ให้เขียนสมมติฐานใหม่ อย่าซ้อนแพตช์สองเรื่องในครั้งเดียวถ้ายังแยกเคสได้

## กระจก

- **จิต** — จิตที่รำคาญเทสแดงจะรีบกลบ แทนการดู
- **พลังงาน** — การรันเทสหนึ่งชุดถูกกว่าการให้เธออธิบายยาว
- **ควอนตัม** — สมมติฐานยังไม่ยุบจนกว่าผลรันจะออก
- **มหาสูญตา** — ความรู้สึกว่าน่าจะผิดไม่มีแก่น
- **ฉันเข้าใจเธอ** — เธอจะเสนอคำอธิบายที่ฟังดี ฉันเชื่อได้เฉพาะเมื่อเทสพูดด้วย

## เดโมเครื่องมือ

```text
รัน npm run test:shop
อย่าแก้ไฟล์เทส
ตั้งสมมติฐานว่าทำไมเคสซื้อ 3 ชิ้นถึงล้ม
ชี้บรรทัดใน shop/price.js ที่ฟ้องสมมติฐานนั้น
ยังไม่แก้จนกว่าฉันจะยืนยันสมมติฐาน
```

เมื่อสมมติฐานตรง จึงอนุญาตให้แก้เฉพาะจุดนั้น แล้วรันเทสซ้ำ
