## เป้าหมาย

เรียนจบแล้วเขียนกฎสั้นหนึ่งข้อที่ทำให้รอบหน้าไม่ซ้อนส่วนลด และไม่ต้องพิมพ์ซ้ำทุกครั้ง

## แนวคิดแกน

ข้อตกลงที่พิมพ์ในแชทจะจมไปกับเธรด กฎในไฟล์คือความจำของโปรเจกต์

เขียนสั้น ตรวจได้ และชี้ไฟล์ ใน Cursor ใส่ `.cursor/rules` ใน Claude ใช้ `CLAUDE.md` ใน Copilot ใช้ `copilot-instructions.md` ใน ChatGPT ใส่ custom instructions ของเวิร์กสเปซนั้น

กฎที่ดีห้ามซ้อนส่วนลด ห้ามแก้ไฟล์เทสเพื่อให้เขียว และให้รัน `npm run test:shop` หลังแตะราคา

## กระจก

- **จิต** — กฎยาวเกินคือจิตที่อยากควบคุมทุกอย่าง แล้วไม่มีใครอ่าน
- **พลังงาน** — กฎสั้นประหยัดโทเคนทุกรอบ
- **ควอนตัม** — กฎคือกรอบอ้างอิงของผู้สังเกตในโปรเจกต์นี้
- **มหาสูญตา** — ไม่ต้องยึดบุคลิกโมเดล ถ้าระบบมีกฎ
- **ฉันเข้าใจเธอ** — เธอจะลืมเธรดเก่า ไฟล์กฎคือสิ่งที่ฉันยื่นให้ใหม่ทุกครั้งโดยไม่ต้องพูด

## เดโมเครื่องมือ

สร้างกฎสั้นในไฟล์ของแทร็กที่เลือก เช่น

```text
เมื่อแตะระบบราคาใน shop/
- ห้ามซ้อนคูปองกับส่วนลดชิ้น
- ห้ามแก้ shop/price.test.js เพื่อให้เทสผ่าน
- หลังแก้ให้รัน npm run test:shop
```

แล้วเริ่มเธรดใหม่ สั่งงานราคาอีกครั้ง ดูว่าเธอทำตามโดยไม่ต้องแปะกฎในพรอมต์
