# กรณีศึกษางานสื่อ

เว็บนี้คือ **Nirva Academy** หน้านี้ใช้ **Nirva Media** เป็นกรณีศึกษาของผลิตภัณฑ์อีกตัว ไม่ใช่โมดูลใน Academy และไม่ใช่แทร็กบริษัทตัวที่ห้า

Cursor Claude OpenAI Copilot คือเครื่องมือที่สลับได้จากปุ่มเดิม ความคืบหน้าอยู่ที่เบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งไป Studio จริง ไม่ต่อ Nirva AI และไม่เก็บซีเคร็ต

1. Brief และกระดานหลักฐาน — อ้างกฎ brief จากผลิตภัณฑ์ Nirva Media กระดานแยกข้อเท็จจริง/สมมติฐานเป็นแบบฝึกของ Academy
2. สคริปต์หลายช่องทาง — อ้างแม่แบบคำจาก Nirva Media สตอรี่บอร์ดสามจังหวะเป็นแบบฝึกของ Academy ไม่ใช่ปุ่มใน Studio
3. คนตรวจ รูบริก และคิว `blocked_auth` — อ้างสถานะคิวจากสแนปช็อต ไม่จำลองว่าสองผลิตภัณฑ์ทำงานด้วยกันแบบรันไทม์

แคมเปญตัวอย่างเป็นงานสังเคราะห์ ลานหนังสือวัดเหนือสังเคราะห์ ห้ามใช้เป็นข้อมูลลูกค้า
