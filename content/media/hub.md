# Nirva Media Lab

เส้นทางเรียนสามตอนในบริบทงานสื่อ ไม่ใช่แทร็กบริษัทตัวที่ห้า

Cursor Claude OpenAI Copilot คือเครื่องมือที่สลับได้จากปุ่มเดิม ความคืบหน้าของแล็บนี้อยู่ในเบราว์เซอร์นี้เท่านั้น ไม่ถูกส่งไป Studio จริง และไม่เก็บซีเคร็ต

1. Brief และกระดานหลักฐาน — reuse กฎ brief จาก NirvaMedia กระดานแยกข้อเท็จจริง/สมมติฐานเป็นแบบฝึกของ Academy
2. สคริปต์หลายช่องทาง — reuse แม่แบบคำจาก NirvaMedia สตอรี่บอร์ดสามจังหวะเป็นแบบฝึกของ Academy ไม่ใช่ปุ่มใน Studio
3. คนตรวจ รูบริก และคิว `blocked_auth` — reuse สถานะคิวจาก NirvaMedia การห้ามให้เธอโพสต์แทนเป็นกฎของคอร์สนี้

แคมเปญตัวอย่างเป็นงานสังเคราะห์ ลานหนังสือวัดเหนือสังเคราะห์ ห้ามใช้เป็นข้อมูลลูกค้า
