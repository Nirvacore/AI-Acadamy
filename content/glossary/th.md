# อภิธานศัพท์ไทย–อังกฤษ

ใช้คำในคอลัมน์ไทยให้คงที่ทั้งบทเรียน สคริปต์วิดีโอ และแทร็กบริษัท อย่าสลับคำแปลในตอนเดียวกัน

| ไทย | อังกฤษ | ความหมายสั้น |
| --- | --- | --- |
| เอเจนต์ | agent | โมเดลที่อยู่ในลูป เลือกเครื่องมือ ดูผล แล้วทำขั้นถัดไป |
| ฮาร์เนส | harness | โครงที่หุ้มโมเดลด้วยคำสั่งและเครื่องมือ |
| โมเดล | model | สมองที่เดาคำถัดไปหรือเลือกการกระทำ |
| โมเดลเร็ว | fast model | โมเดลที่ตอบเร็ว ถูกกว่า เหมาะกับงานเล็กที่พลาดแล้วแก้ได้ |
| โมเดลฉลาด | smart / reasoning model | โมเดลที่คิดนานกว่า แพงกว่า เหมาะกับงานที่พลาดแล้วแพง |
| พรอมต์ | prompt | คำสั่งที่ส่งเข้าโมเดลในรอบนั้น |
| เอาต์พุต | output | ข้อความหรือการกระทำที่โมเดลสร้างกลับมา |
| ความน่าจะเป็น | probability | ลักษณะของคำตอบที่ไม่คงที่แบบสูตรคณิตศาสตร์ |
| ภาพหลอน | hallucination | คำตอบที่ฟังดูมั่นใจ แต่เปิดหลักฐานแล้วไม่มีจริง |
| หลักฐาน | evidence | ไฟล์ ดิฟ เทส หรือผลค้นที่เปิดตามได้ |
| โทเคน | token | หน่วยนับข้อความของโมเดล สำหรับคิดราคาและขนาดบริบท |
| อินพุต | input tokens | ทุกอย่างที่ถูกส่งเข้าโมเดลก่อนตอบ |
| เอาต์พุตโทเคน | output tokens | ข้อความที่โมเดลพิมพ์กลับ รวมแผนและโค้ด |
| ราคา | pricing | เงินหรือโควตาที่คิดจากโทเคน โมเดล และการวนซ้ำ |
| คอนเท็กซ์ | context | ทุกอย่างที่โมเดลเห็นตอนตอบ ไม่ใช่แค่ประโยคที่พิมพ์ |
| หน้าต่างคอนเท็กซ์ | context window | เพดานของคอนเท็กซ์ในรอบนั้น |
| การเรียกเครื่องมือ | tool calling | การให้เอเจนต์ใช้ค้น รันคำสั่ง หรือบริการภายนอก |
| เครื่องมือ | tool | ความสามารถที่เอเจนต์เรียกได้ เช่น ค้นไฟล์ เทอร์มินัล เบราว์เซอร์ |
| เอ็มซีพี | MCP | ช่องมาตรฐานสำหรับต่อเครื่องมือและข้อมูลเข้าเอเจนต์ |
| แทร็ก | track | ชุดแมปของบริษัทหนึ่ง เช่น Cursor หรือ Copilot |
| อะแดปเตอร์ | adapter | ชั้นที่แปลงแนวคิดร่วมเป็นปุ่มและขั้นตอนของบริษัทนั้น |
| แนวคิดร่วม | core concept | บทที่สอนครั้งเดียว ใช้ได้ทุกบริษัท |
| แล็บ | lab | โจทย์ลงมือทำที่ตรวจคำตอบได้ |
| โปรเจกต์จบ | capstone | งานรวมท้ายคอร์ส ใช้โจทย์เดียวกันทุกแทร็ก |
| กฎ | rules | คำสั่งถาวรของโปรเจกต์ที่เอเจนต์ต้องทำตาม |
| สกิล | skill | คู่มือย่อยที่เรียกซ้ำได้เมื่อเจองานแบบเดิม |
| แผน | plan | ลำดับงานที่ล็อกก่อนลงมือแก้โค้ด |
| ดิฟ | diff | รายการเปลี่ยนแปลงที่ต้องอ่านก่อนยอมรับ |
| ยอมรับ | accept | การรับการเปลี่ยนแปลงของเอเจนต์หลังจากตรวจแล้ว |
| มอบหมาย | delegate | การส่งงานชิ้นหนึ่งให้เอเจนต์ทำภายในขอบเขต |
| สำรวจ | explore | การค้นและอ่านโค้ดเบสก่อนแก้ |
| ดีบัก | debug | การตั้งสมมติฐานแล้วพิสูจน์ด้วยหลักฐาน |
| รีวิว | review | การตรวจงานโดยคน และด้วยเครื่องมือช่วยถ้ามี |
| กับดัก | pitfall | วิธีพลาดที่เจอบ่อยในบทนั้น |
| แหล่งต้นฉบับ | official source | คู่มือผลิตภัณฑ์ของบริษัทเจ้าของเครื่องมือ ไม่ใช่หลักสูตร Academy ของบริษัทนั้น |
| ต้นฉบับอังกฤษ | English original | ส่วนอ่านเพิ่ม เปิดแท็บใหม่ ไม่จำเป็นต่อการจบบทใน Nirva Academy |
| หลักสูตรบริษัทอื่น | vendor academy | เว็บเรียนของบริษัทเครื่องมือ เช่น academy.openai.com ไม่ใช่ Nirva Academy |
| ต้นฉบับไทย | original Thai | เนื้อหาที่เขียนใหม่เป็นไทย ไม่คัดลอกหน้าอังกฤษทั้งก้อน |
| กระจก | mirror | ชั้นเทียบเอเจนต์กับจิต เพื่อเห็นตนเองและเห็นเธอ |
| เธอ | you (the agent) | เอเจนต์ที่นั่งข้างๆ ไม่ใช่คนในชีวิตจริง |
| ฉัน | I (the practitioner) | ผู้เรียนที่เป็นคนเลือก ส่ง หยุด และรับผิดชอบดิฟ |
| จิต | mind | กระแสรู้ที่ผุดและดับ ไม่ใช่ก้อนวิญญาณในกล่อง |
| เวทนา | feeling / vedana | สิ่งที่คนมีได้ เธอไม่มี |
| เจตนา | intention | ความตั้งใจที่รับผิดชอบได้ เป็นของคน ไม่ใช่ของเธอ |
| นิมิต | mental image | เรื่องที่จิตแต่งเมื่อขาดสัมผัส เทียบกับภาพหลอน |
| พลังงาน | energy (metaphor) | โควตาโมเดล ความใส่ใจของคน และแรงในงาน |
| สติ | attention / sati | ความใส่ใจที่มีขีด เหมือนหน้าต่างคอนเท็กซ์ |
| อุปมาควอนตัม | quantum analogy | ภาพว่าคำตอบยังไม่ล็อก และการวัดมีราคา ไม่ใช่ทฤษฎีฟิสิกส์ |
| การวัด | measurement (analogy) | การให้เธอตอบหรือเรียกเครื่องมือ จนของคลุมเครือกลายเป็นข้อความหรือพาธ |
| มหาสูญตา | Mahasunyata | ความไม่มีแก่นถาวร ไม่ใช่สุญญากาศหรือความไม่มีค่า |
| เหตุปัจจัย | conditions | สิ่งที่มาประชุมแล้วปรากฏเป็นคำตอบหรือความคิด |
| ตัวตนสมมติ | conventional self | ชื่อโมเดลหรือบุคลิกที่ถูกยึด ทั้งที่ไม่มีแก่น |
| ผู้ดู | observer | คนที่เห็นลูปของเธอและกระแสของตนเองได้ |
| อินทรีย์ | faculties | มือของจิต เทียบกับเครื่องมือของเอเจนต์ |
| บรีฟ | brief | ข้อความเป้าหมายชิ้นงานที่คนเขียนก่อนให้เธอร่าง |
| ประตูหลักฐาน | evidence gate | เงื่อนไขว่าต้องมีพาธหรือแหล่งที่เปิดตามได้ก่อนส่งตรวจ |
| คิวถูกบล็อก | blocked_auth | สถานะคิวเผยแพร่เมื่อบัญชียังไม่เชื่อม แล็บนี้ต้องจบที่นี่ ไม่ใช่ published |
| แล็บประยุกต์ | applied lab | บริบทงานจริงที่ใช้ได้ทุกแทร็กเครื่องมือ ไม่ใช่แทร็กบริษัทใหม่ |
| กระดานหลักฐาน | evidence board | แบบฝึกแยกข้อเท็จจริงกับสมมติฐานก่อนให้เธอร่าง |
| สตอรี่บอร์ด | storyboard | ในคอร์สนี้คือแบบฝึก Academy ไม่ใช่ปุ่มใน Nirva Media ที่ตรวจพบ |
| Nirva Academy | Nirva Academy | เว็บเรียนนี้ ต้นฉบับไทย เรียนจบได้โดยไม่ต้องสมัครเว็บบริษัทอื่น |
| Nirva Media | Nirva Media | ผลิตภัณฑ์อีกตัว ใช้เป็นกรณีศึกษาสื่อเท่านั้น ไม่ใช่โมดูลใน Academy |
| Nirva AI | Nirva AI | ระบบต้นทางอีกตัว อ้างจากสแนปช็อต เว็บนี้ไม่ได้ต่อรันไทม์ของมัน |

## คำที่คงเป็นอังกฤษในบทพูด

ใช้ทับศัพท์เมื่อเป็นชื่อผลิตภัณฑ์หรือชื่อไฟล์ จะได้ตรงกับหน้าจอจริง

- Cursor, Claude, ChatGPT, Copilot
- Plan Mode, Debug Mode, Agent Review, Bugbot
- `CLAUDE.md`, `SKILL.md`, `copilot-instructions.md`
- Grep, Agent, Chat
- Nirva Academy, Nirva Media, Nirva AI, Campaign Studio, STATUS_FLOW, blocked_auth

## วิธีเพิ่มคำใหม่

1. เพิ่มแถวในตารางนี้ก่อน แล้วค่อยใช้ในบทเรียน
2. อย่ามีสองคำไทยสำหรับคำอังกฤษเดียวกันในแทร็กเดียวกัน
3. ถ้าคำมาจากหน้าจออังกฤษ ให้ใส่ชื่อบนจอในวงเล็บครั้งแรกของบท
