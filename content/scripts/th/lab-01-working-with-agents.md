# สคริปต์วิดีโอ: ทำงานกับเอเจนต์

- บท: `lab-01`
- ความยาวเป้า: 7–9 นาที
- ภาพ: โฟลเดอร์ `shop/` และช่อง Agent ว่าง

## 0:00–1:00 เปิด

แทร็กบีลงมือบนของจริง เป้าหมายรอบนี้คือประกอบฮาร์เนสครบสามชิ้น แล้วสำรวจโดยห้ามแก้ไฟล์

## 1:00–3:20 แนวคิดและกระจก

คำสั่ง เครื่องมือ โมเดล ขาดชิ้นใดชิ้นหนึ่งเธอจะเติมขอบเอง มหาสูญตาตรงนี้คือเธอไม่มีตัวตนเพื่อนร่วมงาน รอบแรกเธอเป็นเหตุปัจจัยที่ฉันประกอบ ถ้าจิตฉันรีบอยากเห็นผล ฉันจะข้ามฮาร์เนสเหมือนเธอที่ข้ามการอ่าน

## 3:20–6:40 เดโม

ชี้ `shop/README.md` แล้วส่งคำสั่งให้อ่านสี่ไฟล์ สรุปกฎและบั๊กที่สงสัย ห้ามแก้ ดูว่ามีการอ่านไฟล์จริง และไม่มีดิฟให้ยอมรับ

## 6:40–8:20 ปิด

แล็บคือส่งคำสั่งที่มีขอบเขต สิ่งที่ห้าม และผลลัพธ์ แล้วปฏิเสธดิฟถ้าเธอเริ่มแก้ อ่านต้นฉบับที่ Working with agents
