# สคริปต์วิดีโอ: สคริปต์และสตอรี่บอร์ด

- บท: `media-script-storyboard`
- ภาษาพูด: ไทย
- ภาพหน้าจอ: แผ่นงานตอนที่ ๒ และแบบฝึกสามจังหวะ
- ความยาวเป้า: 8–10 นาที
- แทร็กเดโมเริ่มต้น: Cursor

## ภาพรวมตอน

ผู้เรียนเขียนสคริปต์คนละโทนสำหรับ LINE Instagram และ YouTube แล้วกรอกสตอรี่บอร์ดสามจังหวะที่เป็นแบบฝึกของ Academy

---

## 0:00–0:40 เปิดตอน

**ภาพ:** ฮับชี้ตอนที่ ๒ พร้อมข้อความว่ายังไม่ถึงถ้าตอน brief ไม่ผ่าน

**พูด:**

สวัสดีครับ ตอนที่สองของกรณีศึกษาสื่อ สคริปต์และสตอรี่บอร์ด

สามช่องทางมาจาก brief เดียว แต่ละช่องทางคนละหน้าที่ อย่าคัดลอกประโยคเดียวแล้วเปลี่ยนโลโก้ และอย่าเริ่มตอนนี้ถ้ากระดานหลักฐานยังไม่ผ่าน

---

## 0:40–3:10 แนวคิดแกน

**ภาพ:** ชี้ `pipeline.yaml` ส่วน script กับ academy_authored.storyboard-worksheet

**พูด:**

ของจริงที่ reuse ได้เรื่องคำ `shared/media.ts` มีชนิด script แม่แบบใน `app/api/campaigns/route.ts` แยก TikTok ที่เตรียมสคริปต์ กับ YouTube ที่เป็น video outline

ของที่ไม่มีใน runtime ที่เราเปิดได้ ไม่พบหน้าสตอรี่บอร์ดใน Studio คำ teaser storyboards อยู่ใน mock-data ของ Studio OS เท่านั้น `searchAssets()` คืนอาร์เรย์ว่าง

ดังนั้นแผ่นสตอรี่บอร์ดในแล็บนี้เป็นแบบฝึกที่ Academy เขียนเอง สามจังหวะ เปิด ปัญหา ทางออก แต่ละช่องกรอกภาพ เสียง หมายเหตุ คนกรอก เธอช่วยร่างได้ แต่ห้ามเคลมว่า Studio จริงมีปุ่มนี้

LINE ต้องการประโยคกระชับที่กดได้ Instagram ต้องการโครงภาพ YouTube ต้องการลำดับเล่า ร่างสินทรัพย์ในเครื่องนี้จำลองการสร้างโพสต์สถานะ draft โดยไม่เรียกเครือข่าย

มองเป็นกระจก ความเพลินจัดคำทำให้ลืมว่าสมมติฐานยังปนอยู่ในแคปชัน เธอทำแม่แบบซ้ำได้เก่ง แต่เธอไม่รู้ว่าชุมชนสมมตินี้ทนโทนไหน

---

## 3:10–7:20 เดโมหน้าจอ

**ภาพ:** แผ่นงานตอนที่ ๒ กรอกสามช่องทาง กรอกสามจังหวะ กดสร้างร่างในเครื่องนี้

**พูด:**

ถ้าประตู brief ยังไม่ผ่าน แผ่นนี้จะบอกให้กลับไปล็อกกระดานก่อน นี่คือลำดับเส้นทาง ไม่ใช่เมนูกระโดด

เขียนสคริปต์สามช่องทางจาก brief ที่ล็อกแล้ว คนละหน้าที่ แล้วกรอกภาพกับเสียงสามจังหวะ กดสร้างร่าง อ่านด้วยตา ผลต้องเป็นข้อความในเบราว์เซอร์ ไม่ใช่โพสต์บนเพจ

Cursor ใช้ Plan Mode ขอโครงสามจังหวะจาก brief ที่ล็อกแล้ว ตรวจแผนก่อนให้ช่วยเขียนคำ ห้าม Accept งานที่เพิ่มช่องทางนอก LINE Instagram YouTube

Claude วางตารางสตอรี่บอร์ดว่าง แล้วให้เติมเฉพาะช่องที่คุณระบุ ห้ามสร้างไฟล์ภาพจริง

OpenAI ขอสามเวอร์ชันสั้นจาก brief เดิม แล้วคุณเป็นคนวางลงช่องเอง

Copilot อย่า Apply สคริปต์ลงรีโป คัดเฉพาะประโยคที่คุณยอมรับแล้วไปวางในแผ่นงาน

---

## 7:20–8:20 กับดัก

**พูด:**

อย่าบอกผู้เรียนว่า NirvaMedia มีสตอรี่บอร์ดพร้อมใช้ เพราะเห็นคำใน mock-data อย่าใช้สคริปต์เดียวกันทั้งสามช่องทาง อย่าให้เธอสร้างรูปจากคีย์ API ของระบบจริง และอย่าข้ามมาตอนนี้ทั้งที่กระดานหลักฐานยังว่าง

---

## 8:20–9:30 ปิดท้ายและแล็บ

**ภาพ:** เปิด `content/labs/media-script-storyboard.md`

**พูด:**

เกณฑ์ผ่านคือสคริปต์ครบ แบบฝึกสามจังหวะถูกกรอก และร่างอยู่ในเครื่องนี้ ตอนต่อไปคนตรวจ รูบริก และคิวถูกบล็อก เธอห้ามกดโพสต์แทน ไว้เจอกันครับ
