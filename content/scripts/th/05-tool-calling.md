# สคริปต์วิดีโอ: การเรียกเครื่องมือ

- บท: `core-05`
- ภาษาพูด: ไทย
- ภาพหน้าจอ: UI อังกฤษของเครื่องมือจริง
- ความยาวเป้า: 9–11 นาที
- แทร็กเดโมเริ่มต้น: Cursor

## ภาพรวมตอน

ผู้เรียนเห็นลำดับค้นแล้วค่อยตอบ และเข้าใจว่าเครื่องมือมีราคาเพราะผลถูกอ่านกลับเข้าคอนเท็กซ์

## อุปกรณ์หน้าจอ

- Agent ที่โชว์การเรียก Grep หรือค้นไฟล์
- ผลค้นที่เปิดตามได้
- ถ้ามี MCP ให้โชว์รายการเครื่องมือสั้นๆ โดยไม่เปิดทุกตัว

---

## 0:00–0:40 เปิดตอน

**ภาพ:** แผงเครื่องมือหรือรายการ tool call ใน Agent

**พูด:**

ตอนที่ห้า การเรียกเครื่องมือ เป้าหมายคือมองเครื่องมือเป็นความสามารถของเอเจนต์ และบังคับให้ค้นหรือรันคำสั่งแทนการเดา

โมเดลที่พูดเก่งแต่ไม่แตะโปรเจกต์ จะพาคุณเดินผิดห้องอย่างสุภาพ

---

## 0:40–3:20 แนวคิดแกน

**ภาพ:** ข้อความ `เครื่องมือ = มือ` `โมเดล = สมอง`

**พูด:**

โมเดลอย่างเดียวอ่านได้เฉพาะสิ่งที่อยู่ในคอนเท็กซ์ เครื่องมือทำให้มันแตะโลกจริงได้ ค้นไฟล์ รันเทส เปิดเบราว์เซอร์ หรือเรียกบริการผ่าน MCP

เปรียบเหมือนแม่ครัวที่จำสูตรได้ แต่ถ้าไม่มีทัพพี เตา และตู้เย็น เธอทำได้แค่เล่าเมนู การเรียกเครื่องมือคือการยื่นของจริงให้ลงมือ ไม่ใช่ให้พูดอย่างเดียว

เครื่องมือมีราคา แต่ละครั้งที่เรียก ผลจะถูกอ่านกลับเข้าคอนเท็กซ์ ล็อกเทสทั้งก้อนทำให้รอบถัดไปแพงและวุ่น เครื่องมือผิดใบทำให้เอเจนต์มั่นใจในข้อมูลผิด

เพราะงั้นอย่าเปิดทุกอย่างตั้งแต่เช้า เปิดเท่าที่งานต้องการ แล้วสั่งให้ใช้เครื่องมือเมื่อคำตอบต้องอิงสถานะจริงของโปรเจกต์

มองเป็นกระจก เครื่องมือคือมือของจิต การวัดทำให้ของลอยกลายเป็นพาธที่เปิดได้ ถ้าฉันปิดมือเธอแล้วโกรธว่าเธอเดา นั่นคือฉันยังไม่เข้าใจเธอ มหาสูญตาตรงนี้คือคำตอบที่ยังไม่สัมผัสของ ไม่มีแก่นให้ยึด

---

## 3:20–7:30 เดโมหน้าจอ

**พูด:**

โจทย์นี้เดาแล้วพลาดได้ง่าย ผมจะหาของที่มีอยู่ในรีโป โดยห้ามตอบจากความจำ

```text
หาของที่เกี่ยวกับ core-01 ในโปรเจกต์นี้
ต้องใช้เครื่องมือค้นก่อนตอบ
ตอบเป็นพาธ ชื่อที่พบ และคำค้นที่ใช้
ถ้าไม่พบให้บอกว่าไม่พบ พร้อมคำค้นที่ลองแล้ว
```

**ภาพ:** ชี้ให้เห็นว่ามี tool call ก่อนประโยคสรุป

**พูด:**

สิ่งที่ควรเห็นคือค้นหรือลิสต์ไฟล์ก่อน แล้วค่อยอ่านไฟล์ที่ตรง แล้วค่อยตอบ สิ่งที่ไม่ควรเห็นคือชื่อไฟล์ในประโยคแรกโดยยังไม่ได้อ่านอะไร

เมื่อได้พาธแล้วให้เปิดเอง อย่าให้คำตอบสีสวยแทนการคลิก ถ้าพาธเปิดได้และคำค้นซ้ำได้ งานนี้ถึงจะนับว่ามีหลักฐาน

ถ้าทีมมี MCP ให้เปิดเฉพาะเครื่องมือที่อ่านของจริง เช่น สถานะบิลด์หรือเอกสารภายใน แต่ยังต้องอ่านผลเอง อย่าเพิ่มเซิร์ฟเวอร์สิบตัวแล้วยัดให้เอเจนต์เลือกเองทุกงาน

---

## 7:30–8:30 กับดัก

**พูด:**

อย่าปล่อยให้เอเจนต์ตอบจากความจำทั้งที่ไฟล์อยู่ในเครื่อง อย่าให้รันคำสั่งทำลายข้อมูลโดยไม่อ่านคำสั่ง อย่าเปิด MCP จนเลือกเครื่องมือผิด และอย่าลืมว่าผลเครื่องมือกินโทเคน

ถ้าคำตอบถูกแต่ไม่ยอมค้น ให้ถือว่าท่าผิด งานจริงโปรเจกต์เปลี่ยนทุกสัปดาห์ ความจำของโมเดลตามไม่ทัน
