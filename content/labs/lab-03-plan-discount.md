# แล็บ: แผนก่อนแก้ส่วนลด

- บท: `lab-03`
- เวลา: 10–15 นาที

## โจทย์

ได้แผนที่คนอนุมัติได้ ก่อนอนุญาตให้แตะ `shop/price.js`

## ขั้นตอน

1. ขอแผนโดยห้ามลงมือ
2. ตรวจว่าแผนมีกฎสามข้อ ไฟล์ที่แตะ คำสั่งเทส และสิ่งที่ห้าม
3. แก้แผนถ้ายังให้แตะไฟล์เทส
4. บันทึกแผนที่ล็อก แล้วยังไม่ต้องสร้างในแล็บนี้ถ้าแผนยังไม่ผ่าน

## เกณฑ์ผ่าน

- แผนแตะ `shop/price.js` อย่างเดียว
- มีคำสั่ง `npm run test:shop`
- มีประโยคห้ามแก้ไฟล์เทส
- คนอ่านแผนแล้วพูดได้ว่าจะแก้อะไรก่อน

## เฉลยแนวทาง

ลำดับแผนที่เหมาะ: แก้เงื่อนไข 3 ชิ้น → แยกคูปองไม่ให้ซ้อน → กันราคาติดลบ → รันเทส

## สะท้อนเข้าตัว

1. ฉันเกือบอนุญาตให้สร้างก่อนอ่านแผนหรือไม่
2. แผนนี้สั้นพอที่ฉันจำได้โดยไม่ต้องเลื่อนจอหรือไม่
