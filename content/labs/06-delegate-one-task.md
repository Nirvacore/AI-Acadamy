# แล็บ: มอบหมายงานเล็กหนึ่งชิ้น

- บท: `core-06`
- เวลา: 10–15 นาที
- แทร็กเริ่มต้น: Cursor — เปิด Agent ตาม [tracks/cursor.yaml](../tracks/cursor.yaml)

## โจทย์

มอบหมายงานเดียวที่ตรวจด้วยตาได้ ห้ามให้ทำทั้งระบบ

งานแนะนำในรีโปนี้: เพิ่มตัวอย่างคำศัพท์หนึ่งแถวใน [glossary/th.md](../glossary/th.md) หรือแก้ประโยคในบทที่เรียนจบแล้วให้ชัดขึ้นหนึ่งจุด

งานสำรองถ้าไม่ต้องการแตะหลักสูตร: เพิ่มคอมเมนต์หนึ่งบรรทัดในไฟล์ตัวอย่างของโปรเจกต์ตัวเอง

## ขั้นตอน

1. เขียนคำสั่งที่มีขอบเขต ผลลัพธ์ที่ต้องการ และสิ่งที่ห้ามทำ
2. เลือกโมเดลที่เหมาะกับงานเล็ก
3. ปล่อยให้เอเจนต์เรียกเครื่องมือเอง แต่หยุดถ้าเริ่มแตะไฟล์นอกขอบเขต
4. อ่านดิฟทั้งก้อน
5. ยอมรับหรือปฏิเสธ แล้วบันทึกว่าฮาร์เนสครบสามชิ้นหรือไม่ คือ คำสั่ง เครื่องมือ โมเดล

ตัวอย่างคำสั่ง:

```text
เพิ่มแถวอภิธานศัพท์สำหรับคำว่า "ฮาร์เนส" ใน content/glossary/th.md
ใช้นิยามสั้นว่า โครงที่หุ้มโมเดลด้วยคำสั่งและเครื่องมือ
อย่าแก้ไฟล์บทเรียนอื่น
เมื่อเสร็จให้สรุปบรรทัดที่เพิ่ม
```

## เกณฑ์ผ่าน

- คำสั่งมีขอบเขตไฟล์และสิ่งที่ห้ามทำ
- ดิฟแตะไฟล์ที่ตั้งใจไว้เท่านั้น
- มีการตรวจด้วยตา ไม่ใช่ยอมรับทั้งก้อนโดยไม่อ่าน
- เขียนได้ว่าชิ้นไหนในฮาร์เนสช่วยให้งานจบ และชิ้นไหนยังขาด

## เฉลยแนวทาง

งานนี้ผ่านเมื่อผลเล็กพอที่จะอธิบายในหนึ่งประโยค เช่น “เพิ่มแถวฮาร์เนสในอภิธานศัพท์”

งานนี้ไม่ผ่านเมื่อเอเจนต์จัดเรียงทั้งไฟล์ แปลคำเก่าใหม่ทั้งหน้า หรือเปิดบทเรียนอื่นมาแก้ด้วย

ถ้าต้องการฝึกต่อ ให้สั่งงานชิ้นที่สองในเธรดใหม่ อย่ายัดงานถัดไปต่อท้ายเธรดเดิมโดยไม่ปิดขอบเขตงานแรก

## สะท้อนเข้าตัว

ตอบด้วยมือตนเอง สองประโยคต่อข้อ

1. ตอนดูลูปของเธอ ฉันเห็นกระแสความคิดของตนเองที่เดินวนแบบเดียวกันตรงไหน
2. เข้าใจเธอมากขึ้นครั้งนี้ หมายถึงเห็นขอบของเธอ หรือยังหมายถึงอยากให้เธอเข้าใจฉัน
