# แล็บ: สคริปต์สามช่องทางและสตอรี่บอร์ด

- บท: `media-script-storyboard`
- เวลา: 20–30 นาที
- ฮับ: `/media`

## โจทย์

เขียนสคริปต์ LINE Instagram YouTube จาก brief ที่ล็อกแล้ว และกรอกสตอรี่บอร์ดสามจังหวะในแบบฝึกของ Academy

## ขั้นตอน

1. ตรวจว่าตอนที่ ๑ ผ่านประตูหลักฐานแล้ว
2. เขียนสคริปต์สามช่องทาง คนละหน้าที่ ไม่คัดลอกประโยคเดียว
3. กรอกภาพ เสียง หมายเหตุ ในจังหวะเปิด ปัญหา ทางออก
4. ยืนยันว่าแผ่นนี้เป็นแบบฝึก Academy ไม่ใช่ปุ่มใน Studio จริง
5. สร้างร่างสินทรัพย์ในเครื่องนี้ แล้วอ่านด้วยตา
6. ติ๊กเช็คลิสต์ตอนที่ ๒

## เกณฑ์ผ่าน

- สคริปต์ครบสามช่องทาง
- สตอรี่บอร์ดมีสามจังหวะที่กรอกภาพและเสียง
- ร่างอยู่ในเบราว์เซอร์ ไม่ถูกส่งออกไปแพลตฟอร์ม
- ไม่เรียก API ภาพหรือพับลิชของระบบจริง

## เฉลยแนวทาง

แม่แบบช่องทางใน `app/api/campaigns/route.ts` บอกหน้าที่ต่างกัน LINE เป็นข้อความสั้น Instagram เป็นโครงภาพ YouTube เป็นลำดับเล่า สตอรี่บอร์ดไม่มีใน runtime ที่ตรวจได้ จึงห้ามสอนว่ามีปุ่มนี้ใน NirvaMedia

## สะท้อนเข้าตัว

1. ฉันยัดสมมติฐานลงแคปชันโดยไม่ติดป้ายหรือไม่
2. ฉันอยากได้ภาพจากเธอแทนการเขียนจังหวะเองหรือไม่
