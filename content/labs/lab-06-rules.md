# แล็บ: เขียนกฎให้รอบหน้า

- บท: `lab-06`
- เวลา: 10–15 นาที

## โจทย์

เขียนกฎสั้นของแทร็กที่เลือก แล้วลองเธรดใหม่กับงานราคา

## ขั้นตอน

1. สร้างไฟล์กฎตามแทร็ก

| แทร็ก | ไฟล์ |
| --- | --- |
| Cursor | `.cursor/rules/shop-pricing.mdc` หรือไฟล์กฎของโปรเจกต์ |
| Claude | `CLAUDE.md` |
| Copilot | `.github/copilot-instructions.md` |
| OpenAI | คำสั่งของเวิร์กสเปซหรือ GPT นั้น |

2. ใส่สามข้อ: ไม่ซ้อนส่วนลด, ไม่แก้ไฟล์เทสเพื่อให้เขียว, รัน `npm run test:shop` หลังแก้ราคา
3. เริ่มเธรดใหม่ สั่งงานเล็กเกี่ยวกับราคา โดยไม่แปะกฎในพรอมต์
4. ดูว่าเธอทำตามหรือต้องเตือน

## เกณฑ์ผ่าน

- กฎสั้นอ่านจบในครึ่งนาที
- มีการลองเธรดใหม่
- บันทึกว่าเธอทำตามข้อใดเองได้

## เฉลยแนวทาง

กฎที่ไม่ผ่านคือกฎที่สั่งให้เขียนโค้ดสวยหรือใช้โมเดลที่ชอบ เพราะตรวจไม่ได้จากดิฟ

## สะท้อนเข้าตัว

1. ฉันเขียนยาวเกินเพราะอยากควบคุมทุกอย่างหรือไม่
2. ฉันยอมรับแล้วหรือยังว่าเธอจะลืมเธรดเก่า
