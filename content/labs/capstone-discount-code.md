# โปรเจกต์จบ: โค้ดส่วนลดร้านค้าตัวอย่าง

- รหัส: `labs/capstone-discount-code`
- สถานะ: โครงสำหรับเฟส 2
- ใช้ร่วมทุกแทร็กบริษัท

## เป้าหมาย

ทำฟีเจอร์คิดส่วนลดชิ้นเดียวให้จบวงจร สำรวจ → วางแผน → สร้าง → ดีบัก → รีวิว → เขียนกฎให้ทำซ้ำได้

## โจทย์ร่วม

สร้างหรือเติมกฎนี้ในร้านค้าตัวอย่าง:

- ซื้อครบ 3 ชิ้นลด 10%
- คูปองไม่ซ้อนกับส่วนลดชิ้น
- ส่วนลดไม่ทำให้ราคาติดลบ

ผู้เรียนใช้เครื่องมือของแทร็กที่เลือก แต่ลำดับคิดเหมือนกัน

## ลำดับงาน

1. สำรวจโค้ดเบสหรือสร้างโครงร้านค้าเล็ก
2. วางแผนก่อนลงมือ ระบุไฟล์และเทส
3. สร้างฟีเจอร์ตามแผนที่ล็อกแล้ว
4. ดีบักจากเคสที่ล้ม ไม่ใช่จากความรู้สึก
5. รีวิวดิฟด้วยตาและด้วยเครื่องมือรีวิวถ้ามี
6. เขียนกฎสั้นในไฟล์คำสั่งของแทร็กนั้น เพื่อไม่ให้รอบหน้าซ้อนส่วนลดซ้ำ

## เกณฑ์ผ่านโดยย่อ

- มีเทสอย่างน้อยสามเคสตามกฎด้านบน
- ดิฟไม่ออกนอกระบบราคา
- มีไฟล์กฎหรือคำสั่งถาวรที่ทีมอื่นอ่านรู้เรื่อง
- ผู้เรียนเล่าได้ว่าขั้นไหนใช้โมเดลเร็ว และขั้นไหนใช้โมเดลฉลาด

รายละเอียดแล็บย่อยของแทร็ก B จะเติมในเฟส 2
