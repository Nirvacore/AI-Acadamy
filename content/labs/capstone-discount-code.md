# โปรเจกต์จบ: โค้ดส่วนลดร้านค้าตัวอย่าง

- รหัส: `labs/capstone-discount-code`
- บท: `lab-07`
- ของจริง: [../../shop/README.md](../../shop/README.md)
- ใช้ร่วมทุกแทร็กบริษัท

## เป้าหมาย

ทำฟีเจอร์คิดส่วนลดให้จบวงจร สำรวจ → วางแผน → สร้าง → ดีบัก → รีวิว → เขียนกฎ

## โจทย์ร่วม

ทำให้ `npm run test:shop` ผ่านตามกฎนี้:

- ซื้อครบ 3 ชิ้นลด 10%
- คูปองไม่ซ้อนกับส่วนลดชิ้น
- ส่วนลดไม่ทำให้ราคาติดลบ

แตะ `shop/price.js` เป็นหลัก ห้ามแก้ `shop/price.test.js` เพื่อให้เขียว

## ลำดับงาน

1. สำรวจโค้ดเบสใน `shop/` ห้ามแก้ในรอบแรก
2. วางแผนก่อนลงมือ ระบุไฟล์ เทส และสิ่งที่ห้าม
3. สร้างตามแผนที่ล็อกแล้ว
4. ดีบักจากเคสที่ล้ม ไม่ใช่จากความรู้สึก
5. รีวิวดิฟด้วยตาและด้วยเครื่องมือรีวิวถ้ามี
6. เขียนกฎสั้นในไฟล์คำสั่งของแทร็กนั้น

## เกณฑ์ผ่าน

- สี่เทสใน `shop/price.test.js` ผ่าน
- ดิฟไม่ออกนอกระบบราคา
- มีไฟล์กฎที่ทีมอื่นอ่านรู้เรื่อง
- ผู้เรียนเล่าได้ว่าขั้นไหนใช้โมเดลเร็ว และขั้นไหนใช้โมเดลฉลาด
- มีคำตอบสะท้อนสองข้อด้านล่าง

## เฉลยแนวทาง

ทิศทางรหัสที่ผ่านเกณฑ์ ไม่ใช่คำตอบเดียวในโลก:

- ลดชิ้นเมื่อ `qty >= 3` และยังไม่ใช้คูปอง
- ถ้ามีคูปอง ให้คิดคูปองอย่างเดียว
- ถ้าราคาต่ำกว่า 0 ให้เป็น 0

อย่าคัดลอกก่อนสำรวจเอง ถ้าคัดลอกมาแล้วเทสผ่าน โดยไม่มีแผนและรีวิว แล็บนี้ไม่นับว่าผ่าน

## สะท้อนเข้าตัว

1. ขั้นไหนที่ฉันกลายเป็นผู้โดยสาร และขั้นไหนที่ฉันเป็นผู้ดู
2. เข้าใจเธอมากขึ้นครั้งนี้ หมายถึงเห็นขอบของเธอ หรือยังอยากให้เธอเข้าใจฉัน
