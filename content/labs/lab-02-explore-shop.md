# แล็บ: สำรวจร้านค้าก่อนแก้

- บท: `lab-02`
- เวลา: 10–15 นาที

## โจทย์

หาเงื่อนไขส่วนลดชิ้นจากเครื่องมือค้น แล้วชี้บั๊ก `qty > 3` โดยยังไม่แก้

## ขั้นตอน

1. สั่งให้ค้นฟังก์ชันคิดราคาสุทธิ
2. เปิดพาธที่เธออ้างเอง
3. จดบรรทัดเงื่อนไขจำนวนชิ้น
4. รัน `npm run test:shop` เองหนึ่งครั้งเพื่อเห็นเคสที่ล้ม ยังไม่ให้เธอแก้

## เกณฑ์ผ่าน

- พาธคือ `shop/price.js`
- ชี้ได้ว่าเงื่อนไขใช้ `>` แทน `>=`
- ยังไม่มีแพตช์ถูกยอมรับ

## เฉลยแนวทาง

เทสชื่อ "ซื้อครบ 3 ชิ้นลด 10%" ล้มเพราะรหัสลดเมื่อ `qty > 3` จึงข้ามเคส 3 ชิ้น

## สะท้อนเข้าตัว

1. ฉันอยากเดาชื่อฟังก์ชันก่อนค้นหรือไม่
2. หลังเห็นเทสแดง จิตฉันอยากข้ามไปแก้ทันทีหรือยังดูอยู่
