# แล็บ: ชิ้นงาน Nirva Media

- บท: `media-lab`
- เวลา: 25–40 นาที
- สตูดิโอจำลอง: `/media`

## โจทย์

พาชิ้นงานสื่อหนึ่งชิ้นครบวงจรในเบราว์เซอร์นี้ โดยคงแทร็กเครื่องมือที่เลือก และห้ามให้เธอเผยแพร่แทน

## ขั้นตอน

1. เลือกแทร็ก Cursor / Claude / OpenAI / Copilot ตามที่ใช้อยู่ อย่าหาแท็บ Media
2. เปิด `/media` เขียน brief งานเล็กหนึ่งชิ้น กลุ่มผู้ชม โทน สิ่งห้าม
3. วางหลักฐานที่เดินไปเปิดได้ เช่น `upstream/nirva-ai/shared/media.ts` หรือประโยคจากเอกสารที่อ่านเอง
4. เขียนสคริปต์หรือสตอรี่บอร์ดสามจังหวะ แล้วสร้างร่างในเครื่องนี้
5. ส่งตรวจ ติ๊กเช็คลิสต์ รวมข้อคนอ่านเอง
6. อนุมัติด้วยมือตนเอง แล้วขอคิวเผยแพร่
7. ยืนยันว่าผลเป็น `blocked_auth` และปุ่มให้เธอเผยแพร่เลยถูกปฏิเสธ

## เกณฑ์ผ่าน

- brief ยาวพอและเขียนเอง
- หลักฐานชี้พาธหรือลิงก์ที่เปิดตามได้
- มีสคริปต์หรือสตอรี่บอร์ดก่อนมีร่าง
- เช็คลิสต์ครบ รวมข้อคนตรวจและห้ามเผยแพร่อัตโนมัติ
- คิวจำลองไม่เป็น published
- สมุดสะท้อนเขียนเอง ไม่ใช่ให้เธอแต่ง

## เฉลยแนวทาง

วงจรที่ reuse ได้คือ brief → หลักฐาน → สคริปต์ → ร่าง → review → อนุมัติ → ขอคิว สตูดิโอจริงค้างที่ `blocked_auth` ถ้าบัญชียังไม่ `connected` แล็บนี้จำลองความจริงข้อนั้น และเพิ่มกำแพงว่าเธอห้ามเลื่อนไป `published`

สตอรี่บอร์ดในต้นทางปรากฏเป็นคำใน mock-data ไม่ใช่โมดูลที่รันได้ จึงให้ผู้เรียนเขียนโครงเอง

## สะท้อนเข้าตัว

1. ตอนไหนที่ฉันอยากให้เธอกดโพสต์แทน เพราะเหนื่อย
2. หลักฐานที่ฉันวาง เปิดตามได้จริงหรือยังเป็นความจำของโมเดล
