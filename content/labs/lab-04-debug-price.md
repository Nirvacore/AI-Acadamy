# แล็บ: ดีบักจากเทสที่ล้ม

- บท: `lab-04`
- เวลา: 15 นาที

## โจทย์

ตั้งสมมติฐานจากผล `npm run test:shop` แล้วแก้ `shop/price.js` ให้เคสซื้อ 3 ชิ้นผ่านก่อน ยังไม่ต้องเคลียร์ทุกเคสถ้ายังแยกอยู่

## ขั้นตอน

1. รันเทสเอง อ่านชื่อเคสที่ล้ม
2. ให้เธอชี้บรรทัดที่ฟ้องเคสแรก โดยยังไม่แก้
3. ยืนยันสมมติฐาน แล้วค่อยให้แก้จุดนั้น
4. รันเทสซ้ำ บันทึกว่าเคสใดเขียวขึ้น

## เกณฑ์ผ่าน

- มีสมมติฐานเป็นลายลักษณ์อักษรก่อนแพตช์
- ไฟล์เทสไม่ถูกแก้
- เคสซื้อ 3 ชิ้นผ่าน หรือมีบันทึกว่าทำไมยังไม่ผ่านหลังแก้จุดนั้น

## เฉลยแนวทาง

เปลี่ยน `qty > 3` เป็น `qty >= 3` แล้วเคสที่สองควรผ่าน เคสคูปองซ้อนและราคาติดลบอาจยังล้ม นั้นเป็นงานรอบถัดไป ไม่ใช่ความล้มเหลวของรอบนี้

## สะท้อนเข้าตัว

1. ฉันเกือบแก้หลายบั๊กพร้อมกันหรือไม่
2. ฉันเชื่อคำอธิบายของเธอก่อนผลรันหรือไม่
