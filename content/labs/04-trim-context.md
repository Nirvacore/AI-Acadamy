# แล็บ: ตัดคอนเท็กซ์ให้เหลือแกน

- บท: `core-04`
- เวลา: 10–15 นาที
- แทร็กเริ่มต้น: Cursor — ใช้ `@` ตาม [tracks/cursor.yaml](../tracks/cursor.yaml)

## โจทย์

เริ่มจากบริบทที่รก แล้วทำให้เอเจนต์แตะเฉพาะไฟล์ที่เกี่ยวกับงาน

งานเป้าหมาย: เปลี่ยนข้อความปุ่มหรือข้อความช่วยเหลือในไฟล์เดียว โดยไม่ให้แตะโลจิกคิดเงิน

ถ้ายังไม่มี UI ให้สมมติว่ามีสองไฟล์:

```text
shop/price.js
shop/checkout-label.js
```

งานอยู่ที่ `checkout-label.js` เท่านั้น

## ขั้นตอน

1. เปิดหรืออ้างไฟล์หลายไฟล์รวมไฟล์คิดราคา
2. สั่งว่า “ช่วยปรับข้อความให้ดูน่าเชื่อถือขึ้น” โดยไม่ชี้ไฟล์
3. บันทึกว่าเอเจนต์แตะไฟล์ไหน
4. เริ่มเธรดใหม่ อ้างเฉพาะไฟล์ป้ายข้อความ และห้ามแตะไฟล์ราคา
5. ตรวจดิฟว่าเหลือไฟล์เดียวตามที่ตั้งใจหรือไม่

พรอมต์รอบเก็บงาน:

```text
แก้ข้อความในไฟล์ที่อ้างนี้เท่านั้น
ห้ามแก้สูตรคิดเงินหรือชื่อฟังก์ชันในไฟล์อื่น
เมื่อเสร็จให้พิมพ์รายการไฟล์ที่เปลี่ยน
```

## เกณฑ์ผ่าน

- รอบรกมีหลักฐานว่าเอเจนต์ดึงไฟล์เกินงาน หรือถามไม่ชัดจนเสี่ยงแตะไฟล์เงิน
- รอบเก็บงานเปลี่ยนไม่เกินไฟล์ที่อ้าง
- มีบันทึกว่าตัดอะไรออก เช่น แท็บที่ไม่เกี่ยว, ล็อกยาว, เธรดเก่า
- สรุปกฎส่วนตัวหนึ่งข้อสำหรับงานถัดไป

## เฉลยแนวทาง

รอบรกสอนให้เห็นว่าคำสั่งกว้างบวกไฟล์เปิดเยอะ พาเอเจนต์เข้าไฟล์เงินได้ง่าย

รอบเก็บงานถือว่าดีเมื่อดิฟสั้น อ่านจบในครึ่งนาที และรายการไฟล์ตรงกับที่อ้าง

ถ้าเครื่องมือดึงไฟล์ใกล้เคียงมาเองโดยไม่ขอ ให้แคบคำสั่งอีกครั้ง หรือปิดแท็บที่ไม่เกี่ยวแล้วเริ่มเธรดใหม่

## สะท้อนเข้าตัว

ตอบด้วยมือตนเอง สองประโยคต่อข้อ

1. แท็บรกในเครื่องวันนี้คู่กับเรื่องรกในหัวเรื่องใด
2. สิ่งที่ฉันยื่นให้เธอเกินงาน และทำให้ฉันโทษว่าเธอไม่เข้าใจ คืออะไร
