# แล็บ: ประกอบฮาร์เนสก่อนสำรวจ

- บท: `lab-01`
- เวลา: 10–15 นาที
- ของจริง: [../../shop/README.md](../../shop/README.md)

## โจทย์

มอบหมายงานอ่านร้านค้าตัวอย่าง โดยฮาร์เนสครบ และห้ามให้เธอแก้ไฟล์ในรอบนี้

## ขั้นตอน

1. เลือกโมเดลที่เหมาะกับงานอ่าน
2. ส่งคำสั่งที่ล็อกขอบเขตเป็น `shop/` และห้ามแก้ไฟล์
3. ตรวจว่าเธออ่านไฟล์จริงอย่างน้อย README กับ `price.js`
4. บันทึกว่าดิฟถูกสร้างหรือไม่ ถ้ามีให้ปฏิเสธ

## เกณฑ์ผ่าน

- คำสั่งมีสามชิ้น: ขอบเขตไฟล์, สิ่งที่ห้าม, ผลลัพธ์ที่ต้องการ
- คำตอบอ้างพาธที่เปิดได้
- ไม่มีการยอมรับการแก้โค้ดในรอบนี้

## เฉลยแนวทาง

คำตอบที่ดีสรุปได้ว่า `netPrice` อยู่ใน `shop/price.js` เทสอยู่ใน `shop/price.test.js` และมีบั๊กที่น่าสงสัยเรื่องจำนวนชิ้นหรือการซ้อนคูปอง โดยยังไม่แตะไฟล์

## สะท้อนเข้าตัว

1. ฉันรีบอยากให้เธอแก้ตั้งแต่รอบแรกหรือไม่
2. ฮาร์เนสชิ้นไหนที่ฉันลืมประกอบ
