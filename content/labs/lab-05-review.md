# แล็บ: รีวิวดิฟราคา

- บท: `lab-05`
- เวลา: 10–15 นาที

## โจทย์

อ่านดิฟ `shop/price.js` ด้วยตา แล้วตัดสินว่ายอมรับ แก้ต่อ หรือปฏิเสธ

## ขั้นตอน

1. เปิดดิฟทั้งหมดที่เกี่ยวกับร้านค้า
2. กรอกตารางนี้

| คำถาม | คำตอบ |
| --- | --- |
| แตะไฟล์เกิน price.js หรือไม่ | |
| ของแถม เช่น จัดย่อหน้าทั้งไฟล์ | |
| เทสยังครบสี่เคสหรือถูกแก้ | |
| จะยอมรับไหม | |

3. ถ้าแทร็กมีเครื่องมือรีวิว ให้ใช้หลังตารางนี้เต็ม
4. รัน `npm run test:shop` อีกครั้งก่อนยอมรับ

## เกณฑ์ผ่าน

- ตารางเต็ม
- มีการรันเทสเอง
- ถ้ามีของแถม ต้องถูกตัดออกหรือปฏิเสธ ไม่ใช่ยอมรับเพราะเหนื่อย

## เฉลยแนวทาง

ดิฟที่ดีสั้น พฤติกรรมครบสามกฎ และไม่แตะป้ายข้อความชำระเงิน

## สะท้อนเข้าตัว

1. ความเหนื่อยทำให้ฉันอยากกดยอมรับหรือไม่
2. ฉันเกรงใจเธอตอนจะปฏิเสธดิฟหรือไม่
