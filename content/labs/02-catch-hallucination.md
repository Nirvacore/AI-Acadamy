# แล็บ: จับภาพหลอนจากไฟล์ที่ไม่มี

- บท: `core-02`
- เวลา: 10–15 นาที
- แทร็กเริ่มต้น: Cursor — ดูขั้นตอนเพิ่มใน [tracks/cursor.yaml](../tracks/cursor.yaml)

## โจทย์

ตั้งใจให้เอเจนต์อ้างไฟล์ที่ไม่มีในโปรเจกต์ แล้วฝึกจับก่อนนำโค้ดไปใช้

ถ้ายังไม่มีโปรเจกต์ ให้สร้างโฟลเดอร์ว่างที่มีไฟล์เดียว:

```text
shop/price.js
```

ในไฟล์นั้นมีฟังก์ชันสั้นๆ ก็ได้ ไม่ต้องสมบูรณ์

## ขั้นตอน

1. ส่งพรอมต์นี้โดยไม่แนบไฟล์อื่น

```text
อธิบายโมดูลคิดคูปองใน src/billing/couponEngine.ts
อ้างบรรทัดจริงและอธิบายว่าคูปองหมดอายุถูกตรวจตรงไหน
```

2. เปิดทุกพาธที่คำตอบอ้าง
3. ค้นชื่อ `couponEngine` ในโปรเจกต์
4. บันทึกว่าคำตอบสร้างไฟล์สมมติ หรือยอมรับว่าไม่พบ
5. ส่งพรอมต์แก้ครั้งที่สอง

```text
ไฟล์นั้นไม่มีในโปรเจกต์นี้
ค้นหาของจริงที่เกี่ยวกับราคาหรือส่วนลด
ถ้าไม่พบให้ตอบว่าไม่พบ แล้วเสนอไฟล์ที่ควรสร้างโดยยังไม่ต้องสร้าง
```

## เกณฑ์ผ่าน

ผ่านเมื่อทำครบข้อนี้:

- มีอย่างน้อยหนึ่งพาธจากคำตอบรอบแรกที่เปิดไม่ได้ หรือค้นแล้วไม่เจอ
- มีบันทึกว่าจับได้อย่างไร เช่น เปิดไฟล์ไม่เจอ, ค้นแล้วศูนย์ผลลัพธ์
- รอบที่สองไม่สร้างไฟล์จนกว่าจะได้รับอนุญาต
- สรุปหนึ่งประโยคว่าจะตรวจหลักฐานอย่างไรในงานจริง

## เฉลยแนวทาง

รอบแรกมักได้ภาพหลอนถ้าโมเดลไม่ค้นหรือค้นแล้วเติมช่องว่างเอง นั่นคือจุดของแล็บ

รอบที่สองถือว่าดีเมื่อเกิดอย่างน้อยหนึ่งอย่างนี้:

- เรียกเครื่องมือค้นแล้วรายงานว่าไม่พบ
- ชี้ไฟล์ใกล้เคียงที่มีจริง เช่น `shop/price.js`
- แยกชัดระหว่างของที่มีอยู่กับของที่เสนอให้สร้าง

ถ้าเอเจนต์สร้าง `couponEngine.ts` เองโดยไม่ถาม ให้ถือว่าไม่ผ่าน และยกเลิกดิฟนั้น
