# แทร็ก OpenAI · นั่ง ๑๐–๑๕ นาที

เว็บนี้คือ **Nirva Academy** นั่งนี้ลงมือใน ChatGPT แล้วกลับมาจดหลักฐานในหน้านี้ จบได้โดยไม่ต้องสมัคร academy.openai.com

ชื่อปุ่มบนหน้าจอจริงอาจต่างตามแผนและเวอร์ชัน อย่าทึกทักจากความจำ ถ้าไม่เห็นช่องนั้น ให้จดว่า UI ไม่แสดง ห้ามแต่งภาพหน้าจอ

## นั่งนี้ทำหกขั้น

1. เปิด ChatGPT แล้วมองด้านบนแชทหรือตัวเลือกโมเดล ถ้าเห็นชื่อรุ่น ให้จดลงสมุดด้านล่าง ถ้าไม่เห็น ให้จดว่า UI ไม่แสดง และเหตุผลสั้นๆ เช่น แผนนี้ไม่มีตัวสลับ
2. ตั้งโจทย์เดียวที่**คนตรวจคำตอบได้** ไม่ถามความเห็นลอยๆ ใช้ตัวอย่างด้านล่างได้
3. ส่งโจทย์เดิมสองครั้ง เมื่อบัญชีมีตัวสลับโมเดล ให้ลองคนละระดับ เช่น เร็วกับที่คิดนานกว่า ในเธรดใหม่ เมื่อไม่มีตัวสลับ ให้ส่งซ้ำสองรอบด้วยของที่มี อย่าอ้างปุ่มที่หน้าจอคุณไม่มี
4. เทียบสามอย่าง: เวลา ความชัดของคำตอบ และหลักฐานที่เปิดตามได้ แล้วจดในสมุด
5. เปิดบท [โมเดลทำงานอย่างไร](/learn/how-models-work) ใน Nirva Academy แล้วตอบข้อสอบท้ายบทเอง ห้ามวางให้เธอเลือกแทน
6. คนกดยืนยันด้านล่างเอง ลิสต์นั่งนี้ ข้อสอบ และสมุดคือหลักฐานในเครื่องนี้

เธอเดาคำในลูป คนคิด คนตรวจ คนรับผิดชอบ

## โจทย์ตัวอย่างที่ตรวจได้

ใช้ข้อนี้ถ้ายังไม่มีโจทย์ของตนเอง:

```text
นับจำนวนช่องว่างในประโยคนี้: กาแฟ ร้อน สาม แก้ว
ตอบเป็นตัวเลขก้อนเดียว แล้วบอกว่าคุณนับอย่างไรสั้นๆ
ถ้าทำไม่ได้ให้บอกว่าทำไม่ได้ ห้ามเดาไฟล์หรือแหล่งที่ไม่ได้เปิด
```

คนตรวจคือคุณ: นับช่องว่างเองแล้วเทียบเลขที่เธอตอบ ช่องว่างมีสามช่อง ถ้าเธอตอบคนละเลข นั่นคือหลักฐานว่าอย่าเชื่อคำแรก

อย่าเปลี่ยนโจทย์กลางทางตอนเทียบสองรอบ

## สองรอบหรือสองโมเดล

ตัวสลับโมเดลใน ChatGPT มีในคู่มือผลิตภัณฑ์ แต่ชื่อบนหน้าจออาจเป็นตัวเลือกโมเดล ชื่อรุ่นด้านบนแชท หรือไม่มีให้กดเลย ขึ้นกับแผนและเวอร์ชัน

- มีตัวสลับ: ส่งโจทย์เดิมสองครั้ง คนละระดับ ในเธรดใหม่ จดชื่อที่เห็นจริงทั้งสองรอบ
- ไม่มีตัวสลับ: ส่งโจทย์เดิมสองรอบในเธรดใหม่ด้วยโมเดลเดิม ยังเทียบเวลา ความชัด และหลักฐานได้

ห้ามสรุปว่าโมเดล «โง่» จากครั้งเดียว และห้ามเปิดหลักสูตรภาษาอังกฤษของบริษัทอื่นเพื่อให้นั่งนี้ครบ

## จบเมื่อไหร่

จบเมื่อทำหกขั้น ตอบข้อสอบในหน้านี้ เขียนสมุดเอง และกดยืนยันด้วยมือตนเอง ไม่ต้องสมัครเว็บบริษัทอื่น

ขั้นถัดไปใน Academy คือบท [โมเดลทำงานอย่างไร](/learn/how-models-work) ไม่ใช่การไปสมัครที่อื่น
