# แทร็ก OpenAI ใน Nirva Academy

เว็บนี้คือ **Nirva Academy** แทร็ก OpenAI คือแผนที่ปุ่มของ ChatGPT / Codex ให้ใช้กับบทไทยที่มีอยู่แล้ว ไม่ใช่การพาไปเรียนที่ academy.openai.com

จบบทได้ที่นี่โดยไม่ต้องสมัครหลักสูตรภาษาอังกฤษของบริษัทอื่น

## สิ่งที่ต้องเปิดใน ChatGPT

สรุปจากคู่มือผลิตภัณฑ์ที่เปิดได้จริง (ตัวเลือกโมเดล, ไฟล์ในเธรด, คำสั่งถาวร, เครื่องมือ) ไม่คัดลอกบทของ OpenAI Academy

- **ตัวเลือกโมเดล** — ChatGPT ให้สลับโมเดลในแชท โมเดลเร็วกับโมเดลที่คิดนานกว่าแลกเวลาและโควตา งานเล็กอย่าจ่ายแพง
- **คำตอบกับหลักฐาน** — เธอพูดคล่องได้แม้ยังไม่เปิดไฟล์ คนต้องเดินไปเปิดแหล่ง ถ้าเปิดไม่ได้คือนับภาพหลอน
- **ไฟล์ที่อัปโหลด** — ของที่วางในเธรดกลายเป็นบริบทของรอบนั้น ไม่ใช่ความจำถาวรของโมเดล ทั้งก้อนที่ไม่เกี่ยวกับงานทำให้เธอเดาเก่งขึ้น
- **เครื่องมือ** — ค้นเว็บ รันโค้ด หรือ GPT ที่ต่อเครื่องมือได้ ใช้เมื่อต้องแตะของจริง ไม่ใช่ให้เธอแต่งตัวเลข
- **คำสั่งถาวร** — Custom instructions / Agent instructions อยู่ข้ามแชท คนเขียนกฎ คนตรวจว่าเธอทำตาม

## แบบฝึกและหลักฐาน

1. เปิด ChatGPT แล้วจดชื่อโมเดลที่เลือกลงสมุดด้านล่าง นั่นคือหลักฐานว่าเปิดของจริง ไม่ใช่โลโก้ในหัว
2. เรียนบท [โมเดลทำงานอย่างไร](/learn/how-models-work) ใน Nirva Academy จนตอบสอบสั้นเอง
3. จับภาพหลอนที่ [ภาพหลอนและข้อจำกัด](/learn/hallucinations) ด้วยการเปิดพาธ ไม่ใช่การเชื่อประโยคคล่อง
4. คนตรวจคือคุณ: ติ๊กในข้อสอบท้ายหน้านี้ว่าจบแทร็กโดย**ไม่สมัคร** academy.openai.com

ห้ามให้เธอเขียนสมุดหรือเลือกข้อสอบแทน
