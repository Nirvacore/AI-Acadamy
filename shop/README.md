# ร้านค้าตัวอย่างสำหรับแล็บ

โฟลเดอร์นี้คือของจริงให้ลอง ไม่ใช่โจทย์สมมติ

มีบั๊กตั้งใจไว้ ให้แทร็ก B ได้สำรวจ วางแผน แก้ และเขียนเทส

## กฎที่ต้องการ

- ซื้อครบ 3 ชิ้นลด 10%
- ถ้าใช้คูปอง ห้ามซ้อนกับส่วนลดชิ้น
- ราคาสุทธิไม่ติดลบ

## วิธีลอง

จากรากรีโป:

```bash
npm run test:shop
```

ตอนเริ่มต้นเทสจะล้ม นั่นคือจุดตั้งต้นของแล็บ ไม่ใช่เครื่องพัง

แก้ที่ [`price.js`](price.js) แล้วรันเทสซ้ำจนกว่าจะผ่าน อย่าแก้ไฟล์เทสเพื่อให้เขียวโดยไม่แก้กฎ

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `price.js` | คิดราคาสุทธิ มีบั๊ก |
| `checkout-label.js` | ข้อความปุ่ม ใช้กับแล็บตัดคอนเท็กซ์ |
| `price.test.js` | เกณฑ์ผ่านของกฎส่วนลด |
